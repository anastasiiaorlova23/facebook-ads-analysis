# Facebook Ads Performance Analysis

Analysis of 11 Facebook ad campaigns: spend, ROMI, campaign comparison and recommendations on budget allocation.

**Tools:** Python, pandas, matplotlib, seaborn

📓 [Open the notebook](facebook-ads-analysis-2.ipynb)

## Key findings
- Overall ROMI is 1.26: the account is profitable.
- Trendy (1.91) and Promos (1.76) clearly outperform other campaigns but receive only 3.6% of the budget.
- Expansion and Lookalike take about 67% of spend at an average ROMI of ~1.25.
